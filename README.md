# Explore Bangladesh — MIS 455 Assignment 1

A 5-page static website built with basic HTML and CSS.

- Pages: index, destinations, food, culture, contact (linked with a shared nav bar)
- One external stylesheet: `css/style.css`
- Google Fonts: Poppins + Lora
- `display: flex` — Home (`.flex-row`) and Food (`.flex-cards`)
- `display: grid` — Destinations (`.grid-gallery`) and Culture/Contact (`.grid-2`)
